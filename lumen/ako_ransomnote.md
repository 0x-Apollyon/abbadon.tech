# Ako Ransom Note

> **Entity Summary:** Ako is an inactive/offline ransomware variant associated with the broader Medusa ransomware family. Ako attacks deployed a hybrid cryptosystem utilizing AES-256 for symmetric file encryption and RSA-2048 for key protection. The group combined network locking with threats of publishing exfiltrated data under GDPR regulatory penalties.
